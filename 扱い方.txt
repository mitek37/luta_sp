
(ここでの「ターミナルを開く」とは、luta_spディレクトリをPCのエクスプローラーで開いて、
「何もない所を右クリック」→ 「ターミナルで開く」を押して黒い画面を開くことを指します。)

【必須！まず作業を始める前に】
1.ターミナルを開いて「git pull」を入力しEnter
（これをしないと後のアプデの反映がうまくいかないことがあります。）

【新しい画像を入れる時】
1. ディレクトリ内のimageフォルダに対象の画像を入れる
2. メモ帳等お好きなソフトでdata.jsonを開く

すると、

{
    "～～～.png": {
        "name": "～～～",
        "type": "～～",
        "tags": [
            "～～～",
            "～～～"  ←最後尾のタグのみ、後ろに「,」が付かない
        ]
    },

(中略)

    "～～～.png": {
        "name": "～～～",
        "type": "～～",
        "tags": [
            "～～～",
            "～～～",
            "～～～"  ←最後尾のタグのみ、後ろに「,」が付かない
        ]
    }　←最後尾のデータのみ、後ろに「,」が付かない (※1)
}

こんな感じのものが出てくると思います。

"～～～.png": {
        "name": "～～～",
        "type": "～～",
        "tags": [
            "～～～",
            "～～～"
        ]
    },

の1ブロックが画像1枚に対するデータです。
先頭の"～～～.png"が追加する画像ファイルの名前で
name = 名前(画像ファイルの名前ではなく、サイトで表示する名前)
type = タイプ(資料、設定・小ネタ、イラストのどれかが入ります)
tags = 画像につけるタグ
です。

(途中途中に左に開けられてる空白も意味があるので消しちゃダメよ！)

あとは、追加する画像のデータのブロックを書いて、data.jsonの末尾に追加してあげるだけです。

こ　の　時　！！！

最後尾のブロックが変わるので、元々のブロック後ろの「}」(上の※1)に「,」を付けることを忘れずに！
もちろん追加した後の、最後尾のブロックの「}」には「,」はいりません。

ちなみに元の画像ファイルの名前が「aiscufimreciawm-jrmciaowmc.png」みたいに、長すぎて正味打つのめんどくさいzeっていう場合は、
aisc.pngみたいに元の画像ファイルの名前変えて省略してもいいyo！
その代わり元の画像ファイルの名前と、json内の"～～～.png(または～～～.jpg)"は必ず一致するようにしてね！

ちなみに制限は特にないので
2,3枚(2,3ブロック一気に追加できるyo)

3.データを変えたらメモ帳を上書き保存して閉じてne


【入れ終わったデータをアプデ(反映)させる時】
1.ターミナルを開いて、「git add image」を入力しEnter
2.「git add data.json」を入力しEnter
3.「git commit -m "画像追加"」を入力しEnter
4.「git pull」を入力しEnter
5.「git push」を入力しEnter
